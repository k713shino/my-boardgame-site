## 週末の午後は国分でボードゲームしませんか？

霧島市で活動するエイトマーリンボードゲーム部が、第5回目となる定例ボードゲーム会を開催します。会場は国分駅から徒歩10分の国分パークプラザ。ルール説明付きなので、ボードゲームが初めての方や久しぶりの方も安心してご参加いただけます。

### イベント概要

| 項目 | 内容 |
|------|------|
| 日時 | 2025年10月11日（土）13:30〜16:30 |
| 会場 | 国分パークプラザ2F 中会議室（〒899-4332 鹿児島県霧島市国分中央3丁目9-20） |
| アクセス | JR国分駅から徒歩約10分／近隣に市役所の土日無料駐車場あり |
| 定員 | 10名（途中参加・途中退出OK） |
| 参加費 | 500円（現金のみ／お釣りのいらないようご協力ください） |
| 対象 | 高校生以上〜一般、参加者のお連れ様も歓迎 |
| 申し込み | DMで事前予約受付。当日参加も空きがあればOK |

### 遊べるゲームと持ち込みについて

スタッフがルール説明を担当する予定の軽量〜中量級ゲームとして、スカル・ワードウルフ・カタンなどを用意。気になるゲームの持ち込みも歓迎されています（ルール説明は持ち込んだ方へお願いしています）。手ぶらでふらっと立ち寄っても、みんなで賑やかに遊べるラインアップです。

### こんな方におすすめ

- ボードゲームに興味があるけれど、どこで遊べば良いか迷っている
- 誰かと交流したい、休日をゆったり楽しみたい
- 一人参加でも気軽に参加できるイベントを探している
- 途中参加・途中退出で柔軟に予定を組みたい

お菓子などの軽飲食はOK（アルコールと匂いの強い食べ物はNG）。出入り自由なので、自分のペースでボードゲーム体験ができます。
